# Frozen APK model comparison protocol — 20 October 2026

Question: compare the actual Linear SVM 60/20/20 and freshly retrained Naive Bayes 80/20 models in the delivered APKs, without refitting or changing thresholds. The user has no separate unused labeled SMS test set. This protocol is recorded before computing matched-cohort predictions.

Models are read directly from `Veritxt-0.3.0-LinearSVM-20261019.apk` and `Veritxt-0.3.0-Retrained-NB-80-20.apk`. Verify APK/asset hashes, frozen fitting-artifact hashes, original split membership, matching labels and raw-to-SVM-masked text lineage. Replay original test scores to check exported-model inference against the frozen sklearn models and saved predictions. Keep each model's own preprocessing: the SVM raw-SMS masking adapter and the NB raw URL/amount-preserving tokenizer. Retain each stored decision threshold exactly, including its floating-point representation.

The comparison cohort is drawn from NB's fixed `group-fold-0` test set. Remove all SVM training and validation records and all related components. Build conservative connected components using **both** experiments' saved group relations, exact casefolded raw text, and exact casefolded SVM input views across the full NB corpus. Exclude every component touching NB training or SVM training/validation. No exclusion, threshold or cohort adjustment may depend on predictions or model errors. SVM's validation set is considered exposed because it selected hyperparameters/thresholds; SVM calibration used training folds. Freeze the resulting IDs and input hashes before scoring.

Primary descriptive comparison: smishing-class F1 at the frozen APK thresholds on these same messages. Report accuracy, precision, recall, balanced accuracy, false positive/negative counts and rates, sample/class/component/source support, and paired correct/incorrect outcomes. Independently reconstruct confusion counts. Use 20,000 paired whole-component bootstrap draws, seed 20261020, for the NB-minus-SVM F1 difference. This interval is conditional on the fixed models, labels and retained components; it does not cover selection, fitting variability, label errors or new sources.

This is a **leakage-screened retrospective comparison**, not a fresh unbiased benchmark. Historical test exposure, model-family selection, inherited labels, heuristic grouping and the very small purged cohort prevent a general winner claim, regardless of the observed point estimates or bootstrap interval. The two original test sets may be shown as context but must not be ranked against one another. The displayed app risk score combines model signal and rules; this comparison measures the classifiers, not the UI risk policy or notification accuracy. No APK is rebuilt or modified.
