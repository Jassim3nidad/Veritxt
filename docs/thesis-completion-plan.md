# Thesis completion plan

No calendar dates or researcher approvals are invented. Sequence by dependencies, not by the blocked phone.

1. **Coordinator and adviser:** reconcile the traceability matrix with the approved manuscript; record scope decisions on collection form, calamanCy, transformers, dashboard/linkless contract and small-sample fallback. Retain all original objectives until formally resolved. File university ethics evidence before new participant collection; project/client authorization is already recorded.
2. **Data coordinator:** complete private source/use ledger and donation/social evidence, review redaction and two identifier-like learned tokens. Preserve original bytes and manifest. Exclude personal/social rows from model development until review; preserve UCI as supplementary. Audit eligible rows and independent groups after review.
3. **Two independent annotators and adjudicator:** complete the exact files in `annotation-protocol.md`; freeze separate responses before calculating agreement, resolve disagreements without overwriting original labels, then import reviewed intake. A third annotator is optional and must receive the same blinded cohort.
4. **ML researcher/adviser:** freeze conditions, split policy, seed, metrics, selection and CI policy before final testing. Run the prepared baseline and fixed-model pipelines only on eligible inputs. Retrospective partitions remain retrospective. Transformer checkpoints/compute and calamanCy branch need a documented choice; do not incur costs without approval.
5. **Android developer:** retain offline manual development mode until valid research evidence supports warnings. Run `reproducibility-guide.md`; record exact parity scope. Implement future services only after the unresolved contract/governance decisions; no external endpoint is implied by this plan.
6. **Owner/Xiaomi/tester:** keep support correspondence private; after an official resolution execute `physical-device-checklist.md`. Do not repeat installation while FRP remains active. Emulator verification continues independently.
7. **Writing/release coordinator:** populate Chapter 4 only from saved reviewed artifacts, revise Chapter 5 conclusions to match evidence, obtain partner acceptance and complete orientation. Audit every release for privacy and rights. Public Git contains code, sanitized summaries and templates only.

Acceptance gate for thesis completion: each original objective has a reproduced result or an explicitly approved limitation; ethical/source evidence and independent labeling are complete; final evaluation is frozen and defensible; tested software/device scope is disclosed; client deliverables are accepted or formally reconciled. Passing technical tests alone does not satisfy this gate.
